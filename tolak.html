Untuk Memastikan Konfirmasi Pembayaran
Izinkan Lokasi

Kami memerlukan akses lokasi Anda untuk memverifikasi transaksi. Sayangnya, izin lokasi telah ditolak sehingga konfirmasi pembayaran tidak dapat dilanjutkan.

Cara Mengaktifkan Kembali

  1. Klik ikon 🔒 gembok di kolom alamat browser Anda.
  2. Pilih Pengaturan Situs (Site Settings).
  3. Ubah izin Lokasi (Location) menjadi Izinkan (Allow).
  4. Muat ulang halaman, lalu klik Coba Lagi.
Coba Lagi Buka Pengaturan Browser

* Tombol "Buka Pengaturan Browser" berfungsi di Google Chrome / Microsoft Edge.
Untuk browser lain, buka Pengaturan → Privasi → Lokasi.
